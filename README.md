# Design Token Generator

Java 17+ sample/training project aligned to a **Web Designer** role.

A Java tool that turns a visual theme definition into reusable design tokens and prints CSS-style variables for a UI design system.

## Run

```powershell
mkdir out
javac -d out src\Main.java
java -cp out Main
```

## Notes

- Uses only the Java standard library.
- Intended as a small skills demonstration/training project.
- No passwords, tokens or other secrets should be committed.
